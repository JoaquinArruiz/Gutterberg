### Added

- Fill with AI (AI Mode) has an image model paint each piece's bleed, continuing its art past the edge.
- Edge color bleed fills each piece's bleed with the color along its edge.
- Background colors for the whole sheet and behind each piece.
- Cut marks where the gaps between pieces cross, to cut the inside of the sheet without a ruler.
- Save for sharing writes a readme beside the project with the steps to print it.
- Unsaved work is recovered after a crash, and closing the window with unsaved changes asks first.
- Hold the right mouse button on a piece in the Print tab to see it large.
- Delete or Backspace removes the selected page in the Source tab.
- What's new and a link to Gutterberg's download page in Preferences › About.

### Changed

- The mouse wheel scrolls the row of sheets and the Pages panel sideways.
- Export offers the project's name instead of "New-PDF".
- A shared project finds its PDFs beside it on another computer without asking.
- Projects are saved in a new format, which Gutterberg 1.2 and earlier say they can't open.
