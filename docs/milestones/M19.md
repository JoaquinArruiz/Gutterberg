# M19* — AI Mode (optional)

> **\* Maybe.** This milestone is optional and not scheduled. The owner will decide whether
> to build it after M18. Do not start it, or build anything for it, unless the owner asks.

**Goal:** an opt-in "AI Mode" that adds a few AI-assisted buttons, using the user's own API
key. No chat.

## Principles

- **Off by default.** With AI Mode off, no AI interface appears anywhere: hidden, not
  greyed out.
- **Buttons, not a chat.** Each button sends one request with a fixed prompt and asks for
  structured JSON back (rectangles, grid values, page labels). The app validates the JSON
  and shows it as an editable proposal. The AI never changes the project directly.
- **Same features as local, plus a second engine.** "Detect cards" stays one button (M17);
  AI Mode adds an "AI" engine choice next to "Local". Both return the M17 `Proposal`, so the
  review UI is shared.
- **Privacy:** before anything is sent, a clear notice says which pages go to which
  provider. A text-only mode never sends images.

## Scope

- **Preference:** Preferences › AI Mode. On/off, provider, model, API key (stored in the OS
  keychain via a Tauri plugin, never in project or preference files), and "Test
  connection".
- **Providers:** Anthropic, OpenAI-compatible (covers OpenAI and Grok), Gemini, and Ollama
  for free local models. Each adapter only needs: one image or several, a prompt, and a
  JSON schema for the reply.
- **Buttons:**
  1. **Detect cards (AI engine):** for pages where local detection has low confidence
     (art over the borders, touching cards on a scan).
  2. **Sort pages:** label every page as cards / backs / rules / cover from small
     thumbnails, and pre-fill M11's skip toggles. A 50-page PDF should take one or two
     requests.
  3. *(Later, if wanted)* **Pair fronts and backs** for duplex (M16).
- **Cost:** before a multi-page run, show an estimate (pages, approximate tokens) and ask
  to confirm. Show what each run actually used afterwards.
- **Errors:** invalid JSON, timeouts and refusals show a clear message and leave the
  project unchanged.

## Rough cost (estimates, Anthropic list prices, 2026-10)

- One page image downscaled to about 1000 px: roughly 1–1.5k input tokens; at full
  resolution up to about 4.8k.
- Detect cards on one page with Claude Sonnet 5.5: about $0.01–0.02. Claude Haiku 4.5
  costs roughly half.
- Sort 50 pages from small thumbnails: a few cents.

## Done when

- With AI Mode off, there is no trace of AI in the interface and no network calls.
- With AI Mode on, "Detect cards" and "Sort pages" work with at least the Anthropic and
  OpenAI-compatible adapters, and every result arrives as an editable proposal.
- API keys are stored only in the OS keychain.
