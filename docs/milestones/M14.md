# M14 — Project files, several PDFs and presets

**Goal:** work survives a restart, and one project can take cards from several PDFs.

## Scope

- **Project file: `.gtr`**, a JSON file holding: each source PDF's path, `document_id` and
  content hash, the document layout (groups, grids, freeform cards), the print plan
  (selection, quantities, order, turns) and the output settings. It does not embed the
  PDFs.
  - **Signature first.** The file starts with
    `{ "format": "gutterberg-project", "version": 1, ... }` (write these two keys first).
    This is the file's "magic number" while it stays valid, human-readable JSON.
  - **Checked on open, in Rust**, before anything else, with three clear outcomes:
    1. Not JSON, or `format` missing or different: "This is not a valid Gutterberg
       project file."
    2. Older `version`: migrate silently (versioned migrations, like preferences in
       `src/lib/preferences.ts`).
    3. Newer `version`: "This project was made with a newer version of Gutterberg. Please
       update." Never open it partially.
  - Validated with Zod on the frontend as well.
  - **Moved PDFs:** if a source PDF is missing, ask "Where is this file now?" and accept
    the new location if its hash matches (warn if it doesn't).
  - Later, if "Save with PDFs included" is added: switch to a zip container whose first
    entry names the format (like EPUB / ODF). Not part of this milestone.
  - The app is still called "PDF Card Editor" in the code until M15; use the final
    `gutterberg-project` signature and `.gtr` extension now anyway, so files saved before
    the rename stay valid.
- File menu: New, Open project, Save, Save as, and recent projects. Warn when the PDF's
  hash differs from the one saved.
- **Several source PDFs:** "Add PDF" to a project. The Cards stage gets a document
  switcher; the card library shows cards from every document, filterable by document; the
  Print stage can mix them on one sheet (the M12 engine already supports it).
- **Presets:** save the current grid and spacing under a name ("3×3 poker, 0 mm") and
  apply it to any page group.

## Done when

- Save, quit, reopen: the same layout, plan and output settings are back.
- One sheet holds cards from two different PDFs and exports correctly.
- A preset applied to a page group sets its grid and spacing.
- Migration is tested from a hand-written older project file.
- Opening a non-project file, a renamed PDF, or a file with a higher `version` shows the
  matching message and leaves the current project untouched.
