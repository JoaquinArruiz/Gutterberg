# M14 — Project files, several PDFs and presets

**Goal:** work survives a restart, and one project can take cards from several PDFs.

## Scope

- A `.cardproj` JSON file holding: each source PDF's path, `document_id` and content hash, the document layout
  (groups, grids), the print plan (selection, quantities) and the output settings.
  Versioned with a schema version and migrations, like preferences
  (`src/lib/preferences.ts`). Validated with Zod.
- File menu: New, Open project, Save, Save as, and recent projects. Warn when the PDF's
  hash differs from the one saved.
- **Several source PDFs:** "Add PDF" to a project. The Cards stage gets a document
  switcher; the card library shows cards from every document, filterable by document; the
  Print stage can mix them on one sheet (the M12 engine already supports it).
- **Presets:** save the current grid and spacing under a name ("3×3 poker, 0 mm") and
  apply it to any page group.

## Done when

- Save, quit, reopen: the same layout, plan and output settings are back.
- One sheet holds cards from two different PDFs and exports correctly.
- A preset applied to a page group sets its grid and spacing.
- Migration is tested from a hand-written older project file.
