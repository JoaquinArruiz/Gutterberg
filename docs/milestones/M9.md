# M9 — Render pipeline

**Goal:** no render backlog at any zoom. The magnifier shows a sharp crop within about
150 ms of pressing a handle, even mid-pinch.

Background: main-view tiling is already done (`src/lib/use-viewport-image.ts`,
`view-region.ts`; one request in flight at a time). The magnifier path is not:
`useRegionImage` fires a `render_region` on every zoom step, and the backend re-opens the
PDF for every render and cannot cancel queued work.

## Scope

- **Open-document cache.** Stop re-opening the PDF per call
  (`render_page_png` / `render_region_png` call `load_pdf_from_file` every time).
  pdfium-render's `PdfDocument` borrows `Pdfium`, so it can't simply sit next to it in
  `AppState`. Use a dedicated render thread that owns `Pdfium` and the open document and
  receives requests over a channel; this also serialises pdfium cleanly. Use the existing
  `*_in` functions in `crates/card-core/src/render.rs`.
- **Stale-request skip.** Tag each render request with `(kind, generation)`, where kind is
  viewport, magnifier or thumbnail. Before drawing, the render thread drops queued
  requests that a newer request of the same kind has superseded.
  _As built:_ `card_core::render_worker::RenderWorker`. Only viewport and magnifier requests
  are superseded; thumbnails (a different page each) and the whole-page base layers (one per
  pane) are never dropped, so a fourth kind `page` exists and thumbnails just run last.
  Superseded requests reject with `"superseded"` (`isSuperseded` in `src/lib/tauri.ts`).
- **Magnifier.** Debounce `useRegionImage` (`src/lib/use-region-image.ts`) by 60 ms and
  keep the previous image meanwhile. In `src/components/editor/Magnifier.tsx`, round
  `fullWidthPx` up to quarter-octave steps (`2 ** (Math.ceil(Math.log2(w) * 4) / 4)`) so
  small zoom changes reuse the same scale. Unit-test the rounding.
- Keep pdfium and lopdf work off the async runtime: the render thread above, and
  `tauri::async_runtime::spawn_blocking` for export.
- Replace whole-store reads with per-field selectors in `EditorViewport`,
  `EditorToolbar`, `Magnifier`, `PagePreview`, `OutputPreview` and `OutputNotice`.
- Optional: encode the main view as JPEG (quality 90) instead of PNG. Keep PNG for the
  magnifier, where edges matter.

## Done when

- A 60-event ctrl+wheel pinch over a handle produces at most 5 `render_region` calls
  (log them in dev builds to measure).
- Opening a 100-page PDF and scrolling the thumbnails parses the file once.
- All checks in `CLAUDE.md` pass.
