# M8 — Foundations

**Goal:** CI runs every check on every push, and the app is hardened.

## Scope

- Add `.github/workflows/ci.yml` (ubuntu-latest): install the Tauri Linux deps
  (webkit2gtk-4.1, gtk3), pnpm and Rust, fetch pdfium, then run `pnpm lint`,
  `pnpm typecheck`, `pnpm test`, `cargo fmt --check`, `cargo clippy --workspace -- -D warnings`
  and `cargo test --workspace`. Cache the pnpm store and cargo.
- `scripts/fetch-pdfium.sh`: pin a release tag of bblanchon/pdfium-binaries instead of
  `releases/latest`, and verify a SHA-256 for each target before extracting.
- `crates/card-core/tests/render.rs`: when pdfium is missing, fail if the `CI` env var is
  set; otherwise keep printing SKIPPED.
- `src-tauri/tauri.conf.json`: replace `"csp": null` with
  `default-src 'self'; img-src 'self' blob: data:; style-src 'self' 'unsafe-inline'` and
  confirm the app still loads and renders in `pnpm tauri dev`.
- `src-tauri/src/state.rs`: replace `lock().unwrap()` in `set_path` / `path` with
  `map_err`, as `pdfium()` already does.
- Fix whatever `cargo fmt` and `clippy` report.
- Keep `CLAUDE.md` accurate (commands, rules) if anything above changes them.

## Done when

- CI is green, and the render tests actually run in CI (not SKIPPED).
- The app works in `pnpm tauri dev` with the CSP on.

## Out of scope

- Release builds and installers (M15).
- A `LICENSE` file. The owner will choose the license later; until then the code is
  all rights reserved. Don't add one.
