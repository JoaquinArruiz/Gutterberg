# M21 — Terminology: Source / Print, Original / Preview / Split, "pieces"

**Goal:** the words the user sees match what the app has become. The app handles more than
cards (tokens, tiles, board segments), so the tabs are named after what you do in them,
and the things you cut out are "pieces". User-facing text only; no behaviour changes.

Do this next (before M14), so later milestones write the new words from the start. Follow
the **Glossary** in `CLAUDE.md`; it is the source of truth for every word below.

## Scope

- **Tabs:** "Cards" → **Source** (`EditorToolbar.tsx`, the stage tabs). "Print" stays.
  The internal stage id may stay `cards`; if it is renamed to `source`, migrate stored
  preferences that reference it.
- **Views inside the Source tab:** "Source / Output / Split" → **Original / Preview / Split**
  (`WORKSPACE_LABEL` in `src/lib/preferences.ts`, and anywhere the labels are written out:
  Preferences › Workspace, the layout preview, hints). Keep the internal mode ids
  (`source`, `output`, `split`) so stored preferences stay valid.
- **"card" → "piece"** in user-facing text: the piece library, the piece tool (keep its
  `C` shortcut), freeform pieces, "Group pieces by size", "Selected pieces", "n sheets,
  m pieces", tooltips, empty states, error and pre-flight messages, the Apply grid dialog,
  the About section if it mentions cards. About 140 strings in about 25 components today
  (`src/components/**`, `src/App.tsx`).
  - Measurements become "piece width / height". Keep "card" only for real-world examples
    ("poker cards", "card backs"), which hints may still use.
- **Hints catalog** (`src/lib/hints.ts`, M20): update the texts. Changing a hint's text is
  not a reason to re-show it (don't bump `version`).
- **Docs:** `README.md` (description, controls table, status list wording for the new
  names), `docs/milestones/README.md` direction section. Leave finished milestone briefs as
  written; add a one-line note at the top of M13 and M18 that the UI now says "Source" and
  "pieces".
- **Tests:** update test queries that find elements by text (Testing Library `getByText`,
  `getByRole(..., { name })`). Prefer `data-testid` or roles where a test only depended
  on the wording.
- **Rust:** error messages that reach the UI ("cards that do not fit", pre-flight issues)
  use the new words. Type and function names stay.

## Not in scope

- Renaming code identifiers, files or crates (`CardId`, `card-core`, `CardLibrary.tsx`).
- The product rename to Gutterberg (M15, step 0).
- Non-rectangular pieces.

## Done when

- The app shows "Source | Print" tabs and "Original / Preview / Split" views.
- A search of user-facing strings (components, hints, Rust messages sent to the UI, README)
  finds "card" only in examples and real-world names.
- Stored preferences from before still load (view mode, inspector sections, dismissed
  hints).
- Every check in `CLAUDE.md` passes.
