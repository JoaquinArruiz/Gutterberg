# M18 — Freeform cards

**Goal:** a messy scan works. Cards of different sizes, not lined up and scanned at an
angle can each be selected, straightened, turned to face the same way, sorted, sized and
printed.

Do this after M13. The engine is already prepared: `OrientedRect` sources, the `Freeform`
`CardId` variant (M11), and per-card `turn` and `scale` in `paginate` / `export_sheets`
(M12). This milestone is mostly UI.

## Scope

- **Card tool (Cards stage).** A second selection tool next to the grid tool: draw one
  rectangle per card. Each rectangle can be moved, resized and **rotated**: a rotate handle
  above the top edge, plus an angle field in the sidebar (Shift snaps to 15°). The
  magnifier works on its corner handles. Store them in the page's `freeform` group as
  `OrientedRect`s (normalized in the UI, converted only through `coordinates.ts`).
- **Mixing on one page.** A page can have a grid group, a freeform group, or both (for
  example, a 3×3 grid plus one odd-sized card below it).
- **Straightening.** The source angle is undone on export, so a card drawn at 7° comes out
  straight. The preview shows the card straightened.
- **Turn (Print stage).** In the card library, rotate a card by 90° steps (buttons and
  `R` / `Shift+R`). "Make all portrait" and "Make all landscape" act on the selection.
- **Sort.** Drag cards in the card library to reorder them. The plan's order (Grouped /
  Interleaved) follows this order.
- **Set real size.** Per card or per selection: enter the real size in mm (for example
  63 × 88), or a percentage. The app stores it as `scale`. Show the result as
  "63.0 × 88.0 mm (98.4%)" wherever card sizes appear, and mark scaled cards in the library
  with a small badge, so a scale is never hidden.
- Undo/redo (from M11) covers every edit above.

## Out of scope

- Photos taken at an angle (perspective correction). It would need warping the image,
  which means rasterising. The user should scan the cards instead.
- Automatic detection of card outlines (M17).

## Done when

- A test PDF with cards of three sizes, each tilted by a few degrees and one upside down,
  exports with every card straight, facing the same way and at its source size.
- Setting "63 × 88 mm" on a card that measures 64 × 89.4 mm exports it at 63 × 88 mm, and
  the library shows its percentage.
- Dragging cards in the library changes their order on the sheets.
- Grid groups behave exactly as before.
