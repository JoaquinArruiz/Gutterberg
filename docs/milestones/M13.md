# M13 — Print stage UI

**Goal:** pick cards, set quantities and export a ready-to-print PDF from the app.

Examples that must work:

- Print 9 copies of card 1 on one 3×3 page.
- Choose 3 cards and fill one page with them.

## Scope

- **Stage switch.** A segmented control in `EditorToolbar`: Cards | Print. Add `stage` to
  `ui-store`. Each stage registers its own panels with the workspace layout system
  (`src/lib/workspace-layout.ts`, `src/components/workspace/`) and remembers its own layout.
- **Card library panel.** A virtualised grid of card thumbnails, each rendered with
  `render_region` at a small width and cached by `CardId` + width. Filter by page or group.
  Click selects a card and shows a quantity stepper (0–99); Shift-click selects a range.
  "Select all" and "Clear".
- **Plan.** "All cards in order" (today's behaviour, the default) or "Custom selection".
  An **Auto-fill** toggle repeats the selected cards until the last sheet is full.
- **Sheet preview.** Pages from `compute_sheets`, drawn with the card crops (same approach
  as `OutputPreview`). Page navigation and an "n sheets, m cards" summary.
- **Inspector.** Move output spacing, page size, orientation and margins here from the
  Cards sidebar, plus the sheet grid (rows × columns, or Auto).
- **Export** from the Print stage calls `export_sheets`, with the M11 pre-flight.

## Done when

- Both examples above work end to end.
- "All cards in order" exports the same file as before this milestone.
