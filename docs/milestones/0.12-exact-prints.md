# 0.12.0 — Exact prints: size presets and a calibration sheet

Two things that help the paper come out right: choosing a common piece size in one click, and finding the duplex
offset by measuring instead of guessing.

## Part 1 — Piece size presets

Today a real size is typed in Print › Selected pieces. The image size dialog has three fixed presets of its own
(`SIZE_PRESETS` in `src/lib/images.ts`: standard 63 × 88, small 59 × 86, tarot 70 × 120). A user who sleeves into
62 mm wide "perfect fits" resizes every set by hand.

### Steps

1. **One list of sizes.** Built-in presets in `src/lib/` shared by Selected pieces and the image size dialog, which
   drops its own list. Start from the sizes sleeve makers sell (poker 63.5 × 88.9, standard 63 × 88, mini American
   41 × 63, mini Euro 44 × 68, Euro 59 × 92, Japanese 59 × 86, square 70 × 70, tarot 70 × 120); check each against
   at least two sleeve makers' size charts before writing it down.
2. **A preset may fix only the width** (or only the height), keeping the piece's proportions, for cases like
   "62 mm wide". This uses the existing chain icon: a one-sided preset sets the size with the chain linked.
3. **Your own presets.** Save the size of the selected pieces as a preset with a name; rename and delete them.
   Stored in preferences (`sizePresets`, preferences version 13), like grid presets (`MAX_PRESETS`,
   `MAX_PRESET_NAME`).
4. **In Selected pieces**, a "Size preset" menu next to the real size fields. Choosing one sets the real size of the
   selected pieces: an explicit, visible per-piece setting, as `AGENTS.md` requires. It is one undo step.
   Pieces of different proportions with a two-sided preset are stretched, so say so before applying (or offer
   width only).
5. **Texts, docs, changelog.**

## Part 2 — Printer calibration sheet

Print › Duplex has "Back offset X / Y" (`offset_x_mm`, `offset_y_mm` in `DuplexOptions`), but nothing helps find
the numbers.

### Steps

1. **The sheet.** `card-core` writes a two-page PDF (front, back) at the chosen sheet size and flip (long or short
   edge): on the front, thin lines at known places (the centre and near each corner); on the back, at the same
   places as seen through the paper (using the same mirroring as the backs, see `finish.rs`, the function that
   turns a back for the flip), short rulers from −5 to +5 mm with ticks every 0.5 mm. Held up to a light, the front
   line crosses the back ruler at the offset. A 100 mm line on the front checks that the printer prints at actual
   size, not "fit to page". Vector only; texts in the standard Helvetica font, numbers and arrows mostly, the few
   words passed in from the UI in the user's language.
2. **In Print › Duplex**, "Print a calibration sheet…" saves that PDF; a small dialog explains the three steps
   (print on both sides at actual size, hold to the light, type the two numbers read at the centre) and fills the
   offset fields, with the sign worked out for the user. If the corners read differently from the centre, say the
   printer also turns or scales the back, which an offset cannot fix.
3. **Gutterfold** needs no calibration; the button is only shown for duplex sheets.
4. **Tests** in `crates/card-core/tests/` (the marks land where expected for both flips and both orientations) and
   for the dialog's sign conversion.
5. **Texts, docs (`docs/controls.md`), changelog.**

## Out of scope

- Correcting rotation or scale between the sides (only a translation, as today).
- Per-printer profiles. The offset stays in the project, as today.

## Done when

A preset sets the size of the selected pieces in one step and can be undone; the user's presets survive a restart;
printing the calibration sheet and typing what it shows lines up the backs on a real printer (the owner checks one
long-edge and one short-edge print); every check in `AGENTS.md` passes.
