# 0.13.0 — Turn a grid into pieces

The first of two versions for "several grids on one page". Requested by a user: "Some PNPs have 3 different sizes of
components or 2 different orientations to fit the page better."

## Where it stands

- A page belongs to one page group (`PageGroupKind` in `crates/card-core/src/card.rs`): one grid, skipped, or
  freeform. A grid covers only its region of the page (`selection` in `GridGroup`, `src/lib/document-layout.ts`).
- A page with a grid can **also** have freeform pieces: `toRustGroups` (`src/lib/print-request.ts`) puts a page's
  freeform pieces right after its grid pieces. So two sizes on one page already work, if one of them is drawn piece
  by piece with the Piece tool.
- The same PDF can be added to a project twice, with a different grid on each copy.

## Goal

A grid can be turned into freeform pieces in one step: each cell becomes a freeform piece at the same place and
size. The page is then free for the next grid. Three sizes on one page take: grid, turn into pieces, grid, turn into
pieces, grid.

## Steps

1. **The action.** "Turn into pieces" in the Source sidebar's grid section, for the viewed page. Each cell of the
   grid becomes a freeform piece (in page order: row by row), appended to the page's freeform pieces; the grid's
   region is cleared. One undo step.
2. **Keep what the user set.** Per-piece edits (copies, turn, size, back, place in the order) move from the grid
   piece's id to the new freeform piece's id, like `editsAfterDelete` and `editsWithoutFreeform` do for deletions
   (`src/stores/layout-store.ts`). Backs that point at a turned piece follow it too.
3. **Page groups of several pages.** The grid of a group applies to all its pages; turning it into pieces on one page
   must ask: this page only (the page leaves the group, as "Apply this grid to…" splits groups today) or every page
   of the group.
4. **Say it's possible.** A help tip the first time someone draws a grid on a page that already has freeform pieces
   or turns a grid into pieces, and a line in `docs/controls.md`: a page can have one grid and any number of
   freeform pieces.
5. **Tests** for the conversion (positions in mm equal the grid cells; edits follow; undo restores the grid).
6. **Texts, changelog.**

## Out of scope

- Turning freeform pieces back into a grid.
- Several live grids on one page: that is 0.14.0.

## Done when

On a page with two sizes of pieces, drawing a grid for the first, turning it into pieces and drawing a grid for the
second gives every piece in the library with its edits kept; every check in `AGENTS.md` passes.
