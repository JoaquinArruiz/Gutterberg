# M16 — Print features (outline)

Firm this up with the owner before starting. All in the Print stage and `paginate`.

- **Cut marks:** short lines in the margins at each card edge, or full lines in the gaps.
  Thickness and colour configurable.
- **Bleed:** extend each card by n mm. Take it from the source when the source has
  spacing, or mirror the edge strip (vector-safe: draw the form again, clipped and flipped).
- **Duplex:** a backs sheet per fronts sheet, mirrored horizontally, with an x/y offset to
  correct printer drift.
