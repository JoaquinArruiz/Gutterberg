# M22 — UI consistency and polish

**Goal:** before the first public release (M15), make the interface consistent: shared
controls instead of browser defaults and copied styles, one recognizable look for AI
actions, explanations behind info tips instead of filling the sidebars, movable panels in
the Print tab, a fix for cropped top/bottom panels, and a tidier Preferences window with an
About section that links to the author.

No engine changes. Every new string goes into both `src/locales/en.json` and `es.json`
(neutral Spanish, `tú`). Keep the existing look wherever nothing below asks for a change.
Use pnpm for every package (never npm or npx).

## 1. Shared controls (`src/components/ui`)

Keyboard and screen-reader support built in. Radix UI primitives are fine (MIT,
`pnpm add`); hand-written components must use the right roles and keys.

| Component | Use | Replaces / examples |
| --- | --- | --- |
| **Button** | Variants `default`, `primary`, `ghost` (icon), `danger`, `ai` (section 2) | The `smallBtn` class string copied into 8 files (`DetectSection`, `PropertiesSidebar`, `PresetsSection`, `FreeformSection`, `PrintInspector`, `FinishSections`, `SelectedCardsSection`, `CardLibrary`) and `iconBtn` in 2 (`HintToast`, `DocumentName`) |
| **Switch** | On/off settings | Link gaps, Live preview, Auto-fill, Group pieces by size, Duplex on, and similar |
| **Checkbox** | Items in a list; custom styled with the accent colour and a check icon | Include/skip per page in the Pages panel |
| **Segmented** | 2–3 short options, styled like the Source / Print tabs | Order Grouped / Interleaved, flip Long / Short, bleed Mirror / Source, orientation |
| **RadioCard** | Options that need a description (title + one line) | Preferences choices, the Apply grid target |
| **InfoTip** | A small circled "i" (lucide `Info`) after a label or section title | One-line explanations in the sidebars and the Print inspector |

- Replace all 13 native `type="checkbox"` / `type="radio"` inputs today (`GapFields`,
  `PreferencesDialog`, `PagesPanel`, `ApplyGridDialog`, `PrintInspector`, `FinishSections`)
  with the right control from the table.
- **InfoTip** opens on hover, keyboard focus and click, closes with Esc, and is announced to
  screen readers (`aria-describedby`). Only explanations move behind it: **warnings, errors
  and anything the user must act on stay visible.** The brief's "As built" section lists
  which texts moved.

## 2. AI actions

- An `--ai` colour token: a soft violet, defined for light and dark themes next to
  `--accent` in `src/index.css`.
- AI actions are their own buttons (`Button` variant `ai`): lucide `Sparkles` **in front of
  the text**, in the AI colour, with a thin AI-coloured border. **Icon-only** AI buttons get
  a small spark badge in the top-right corner instead.
- **Detect pieces:** replace the Local / AI radio. "Detect pieces" (local) stays the main
  button; "Detect with AI" sits next to it as the AI button. Do the same for every other AI
  control (Sort pages, and any others M19 added).
- While a request runs, the spark pulses (respecting `prefers-reduced-motion`); the tooltip
  names the provider ("Sends this page to <provider>").
- With AI Mode off, nothing AI-related shows, as today.

## 3. Movable panels in the Print tab

- Register the piece library and the Print inspector in the same workspace layout system
  the Source tab uses (`src/lib/workspace-layout.ts`, `src/components/workspace/`):
  positions, presets, remembered sizes, the panels menu.
- **A separate layout per tab:** moving a panel in one tab never moves it in the other.
- The sheet preview stays in the centre (like the page view in Source), and its sheet strip
  stays inside it.
- Migrate the stored Print widths (`prefs.print.layout`) into the new layout, with a
  preferences version bump and a migration test.

## 4. Bug: panels at the top or bottom are cropped

- Likely cause: the Pages panel's horizontal size in `src/lib/workspace-layout.ts` is 124 px
  by default and 100 px minimum, but one row of thumbnails needs about 160 px (28 px header
  + padding + the 84 px thumbnail + page number + bottom padding + horizontal scrollbar).
- **Reproduce it first**, with Live Preview on and off and in each view
  (Original / Preview / Split), then size the strip from its real content (derive it from
  `THUMB_HEIGHT` instead of a fixed number).
- Check the Print tab's panels at the top and bottom too, once they're movable.
- If the cause turns out to be different, tell the owner before changing anything.

## 5. Preferences

- **Section icons** (lucide): General `Settings`, Workspace `LayoutPanelLeft` (same as the
  panels menu), Preview `Eye`, Appearance `Palette`, AI `Sparkles` (in the AI colour), About
  **the app's own icon** (the circled "i" stays reserved for InfoTip).
- **Only About sits at the bottom** of the section list, separated by a spacer.
- **About** shows the app version and two links, each with its official logo from
  [Simple Icons](https://simpleicons.org) (CC0, unmodified, inline SVG; lucide has no brand
  icons):
  - LinkedIn: `https://www.linkedin.com/in/joaquinarruiz`
  - GitHub: `https://github.com/JoaquinArruiz`
- Clicking a link first asks in a native dialog (the existing `ask`): "This will open your
  web browser at:" followed by the exact URL, with Open / Cancel. Then open it with Tauri's
  **opener plugin**, with its permission in `src-tauri/capabilities/default.json` scoped to
  exactly those two URLs.
