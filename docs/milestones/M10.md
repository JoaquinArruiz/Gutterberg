# M10 — Export correctness

**Goal:** real publisher PDFs export correctly, or fail with a message that names the page.

All in `crates/card-core/src/export.rs` unless noted.

## Scope

- **Page boxes.** `page_box` takes the first CropBox *or* MediaBox it finds walking up
  `/Parent`. Resolve MediaBox and CropBox separately, each with inheritance, then intersect
  CropBox with MediaBox (as pdfium does). Check that pdfium's page size matches for the
  test fixtures.
- **Catalog cleanup.** Drop `/Outlines`, `/Names/Dests`, `/StructTreeRoot`, `/AcroForm`
  and `/OpenAction` from the catalog before `prune_objects`, so the old pages and their
  content streams are actually removed. Test that output size stays close to input size.
- **Form fidelity.** `page_to_form`: copy the page's `/Group` (transparency) onto the form.
  Reject `/UserUnit` ≠ 1 with a clear error.
- **Limits.** Decompress page content with a size cap (about 256 MB). Check which API
  lopdf 0.45 offers (a `get_page_content_with_limit`-style function); otherwise decode
  streams manually with a cap. Treat a decode failure as an error instead of copying the
  raw stream into the form.
- **Atomic save.** `export_pdf`: write to a temp file in the output folder, then rename.
  In `src-tauri/src/commands/export.rs`, canonicalize both paths before checking that the
  output isn't the open input.
- **Rotated pages.** Support `/Rotate` 90, 180 and 270 instead of returning
  `UnsupportedRotation`. The UI selection is made on the rotated (displayed) page, so map
  the normalized bounds back to the unrotated box, then put a rotation matrix on the form
  so cards come out upright. Add a fixture per angle to `sample.rs` and assert card
  positions in the output.
- README: one line saying export removes encryption and permissions.

## Done when

- Fixtures for rotated pages, a CropBox offset, inherited boxes and a document with
  outlines all export and pass `qpdf --check` (add it to CI if easy to install).
- For each fixture, the pdfium preview of the source and the exported card positions agree.
