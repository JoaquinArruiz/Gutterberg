# M15 — Distribution (outline)

Firm this up with the owner before starting.

- A `tauri-action` workflow that builds `.msi`, `.dmg` and `.AppImage`/`.deb` on tag push,
  with pdfium bundled for each platform (pinned, as in M8).
- Publish to GitHub Releases; add the Tauri updater plugin.
- Signing: macOS notarisation needs an Apple developer account. Decide with the owner
  whether unsigned builds are acceptable first.
- README: screenshots or a GIF, a short "why", and a download link.
