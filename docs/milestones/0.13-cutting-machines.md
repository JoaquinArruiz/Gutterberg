# 0.13.0 — Cutting machines

Cut marks today are for a knife or a trimmer (`MarkStyle::Ticks` and `Gaps` in `finish.rs`). People with a cutting
machine need two other things: marks the machine's camera finds on the printed sheet, and a file with the cut lines.

## Goal

Print › Cut marks can add registration marks for a print-and-cut machine, and Export can also write the cut lines of
every sheet as SVG or DXF, at the exact place of each piece.

## Steps

1. **Research first, write it into this brief.** For Silhouette (the most common print-and-cut machine): the shape,
   size and position of its registration marks and the area they leave for pieces, from Silhouette's own
   documentation. Check whether Brother ScanNCut and Cricut can use either output: Cricut's Print Then Cut adds its
   own marks to an uploaded picture and is probably out of scope; say so in the docs if it is.
2. **Registration marks** as a new option in Print › Cut marks, next to the current styles (they can be used
   together). The sheet engine reserves their area like a margin, so pieces never sit under a mark, and reports
   overflow as usual when the pieces no longer fit. Drawn as vector content in the export and shown in the preview
   (`SheetOverlay`).
3. **Cut file.** "Also save the cut lines" in the export: one SVG (and/or DXF) per sheet, or one with a layer per
   sheet, in millimetres with the same origin as the PDF page, so it lines up with the registration marks. Each
   piece is a closed rectangle, at its edge (not including the bleed). An optional corner radius rounds the cut
   path only; the artwork stays a rectangle. Ask the owner whether the corner radius fits the "rectangles only"
   decision before building it.
4. **Project version 6** for the new finishing settings, with a migration that turns them off for older projects.
   Older Gutterbergs refuse it as usual.
5. **Tests** in `crates/card-core/tests/`: marks never overlap pieces; the cut file's rectangles equal the
   placements; a project version 5 opens with everything off.
6. **Texts, docs (`docs/controls.md`, `docs/architecture.md` › Finishing), changelog.** Glossary: these are still
   **cut marks**; "registration marks" is the machine's term and can be used next to it.

## Out of scope

- Driving a machine directly or writing its native file format (`.studio3` and others).
- Shapes other than rectangles in the cut file, beyond an optional corner radius.

## Done when

A sheet with registration marks, printed on a real Silhouette, is read by Silhouette Studio and cut where the pieces
are, using the exported cut file (the owner or a tester checks this once); every check in `AGENTS.md` passes.
