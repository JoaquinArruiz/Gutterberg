# M17 — Auto-detect card grids and card outlines (outline)

Firm this up with the owner before starting.

- **Grids:** raster analysis of a low-resolution render; find long horizontal and vertical
  edges, then cluster them into a grid (rows, columns, bounds, source gap).
- **Messy scans:** find each card's outline (contour detection on the render) and propose
  one freeform `OrientedRect` per card, including its tilt. This is where detection saves
  the most clicks.
- Propose the result as a selection the user confirms or adjusts; never apply it silently.
- Vector-path detection can come later.
